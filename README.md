# Cifra – Web app (maquetación HTML)

Maquetación HTML de la web app de Cifra (ENG-2314), a partir de los prototipos de `cifra-prototipos` (Polaris Web Components 2.0-rc).
Abrir `login.html` para entrar como usuario, o `index.html` para el inventario de componentes y pantallas.

Respecto a la app embebida en Shopify, la web app suma:
- **Sidebar** de navegación (inspirado en Linear), inyectado por `shared/cifra.js` en todas las pantallas de la app. ⌘K / Ctrl K abre la búsqueda y `[` pliega el sidebar.
- **Login / Sign up** (`login.html`): Shopify, Google o email con código.

Los cambios del sidebar están documentados en `index.html`.

Local: `node serve.js` → http://localhost:4321
